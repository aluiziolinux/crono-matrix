ALPHA EVAL OBSERVATORY

1. Atualize os dados:
   node tools/generate-dashboard-data.mjs

2. Abra index.html com duplo clique.

O dashboard funciona offline e não envia dados. Para importar checkpoints de
outra pasta, use --extra-root=/caminho. A visão simples explica os resultados
sem jargão; a visão acadêmica mostra cobertura, intervalos, proveniência e
limitações metodológicas.
